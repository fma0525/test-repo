# 病理中心作業模擬（第一階段：流程模擬與作業管理儀表板）

用離散事件模擬把病理中心的每一件檢體從收件跑到發報告，找出瓶頸、時段錯配與批次等待，
並推估件數成長時哪個資源會先不夠用。參數全部放在 Excel，方便日後換成實際資料。

> 目前所有數字都是**假設值**，請逐步用 LIS 統計、班表與設備規格取代。

## 快速開始

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows：.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

瀏覽器打開後，按左側「▶ 執行模擬」。

## 儀表板分頁

| 分頁 | 回答的問題 |
|---|---|
| 總覽 | 平均 TAT、P90、達標率、自動判讀的重點發現 |
| 瓶頸與產能 | 哪個資源最忙、哪個階段等最久；節拍時間與負荷率（不需模擬也能算） |
| 時段負荷 | 平日每小時各資源的使用率熱圖；一週的在製品（WIP）變化；Little's Law 驗證 |
| 價值流 | 每件檢體的時間花在作業、設備、排隊、批次等待、必要等待各多少；脫水機滿載率 |
| 成長規劃 | 依年成長率推估各資源哪一年超過警戒；逐年模擬 TAT 變化 |
| 增員實驗 | 各站多 1 人，TAT 改善多少（參考劍橋 WSC 2024 論文圖 5 的實驗設計） |
| 參數設定 | 直接在網頁改參數，或下載 / 上傳 Excel |

## 流程模型

```
收件 → 固定（中大型檢體） → 取材 → 脫水機（依排程開機，批次）→ 包埋 → 切片
     → 染色封片機（湊批）→ 品管配片 → 數位掃描（可關閉）→ 判讀
     → 加做特殊染色與補判讀（部分檢體）→ 發報告
```

- 人力與設備依班表（每 30 分鐘一格）上下班；同一資源可設定多個班別。
- 急件在每一站優先排隊；脫水機與染色機裝載也是急件優先。
- 脫水機：同一件檢體的蠟塊不拆批，只裝適用該程序的檢體，裝不下的等下一次。
- 每段時間都歸類為「作業 / 設備處理 / 排隊等待 / 批次等待 / 必要等待」，用於價值流分析。

## 參數 Excel

預設檔在 `config/病理中心模擬參數_預設假設值.xlsx`，包含六個工作表：

| 工作表 | 內容 |
|---|---|
| 一般設定 | 每日件數、週末比例、數位流程開關、特殊染色比例、染色機批次、模擬週數、成長率等 |
| 檢體類型 | 各類型比例、急件比例、蠟塊數、每塊玻片數、取材與判讀時間、固定時數、TAT 目標 |
| 作業時間 | 各作業的時間（三角分布：最短、最可能、最長）與使用的人力 / 設備 |
| 人力與設備班表 | 每個資源的數量與平日、週六、週日上班時段 |
| 脫水機排程 | 每個程序的星期、開機時間、時數、台數、容量、適用檢體 |
| 到件時段 | 每小時到件的相對權重 |

每個表都有「來源」欄，換成實際資料時請記錄出處。

## 程式結構

```
app.py                    Streamlit 儀表板
pathlab_sim/config.py     參數預設值、Excel 讀寫與檢查
pathlab_sim/model.py      salabim 離散事件模擬模型
pathlab_sim/analysis.py   作業管理分析：KPI、瓶頸、價值流、靜態產能、成長、增員實驗
pathlab_sim/charts.py     圖表
tests/                    模型檢查（時間守恆、Little's Law、容量不超載、可重現性等）
docs/papers/              參考論文摘要
```

執行測試：`python -m pytest -q tests`

## 目前的簡化

- 人員下班時，手上的工作會做完才離開（視同延後下班）。
- 站點間的運送時間與送件人員尚未模擬（第三階段接平面圖後加入）。
- 同一件檢體的所有蠟塊、玻片一起移動。
- 脫水機只依排程開機，沒有「湊滿一台就提早開機」。
- 沒有區分次專科分工。
